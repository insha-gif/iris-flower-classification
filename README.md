# iris-flower-classification

A simple Machine Learning project classifying Iris flower species using Logistic Regression and Random Forest models in Python.

#What I Did

1. Data Preparation:

2. Preprocessing:
   Split the data into train/test sets (80-20 split) and applied standard scaling to normalize feature values.
